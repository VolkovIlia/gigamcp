# Как помочь проекту

Спасибо, что хотите сделать GigaMCP лучше. Issues и pull requests принимаются на русском и на английском.

## Сообщить об ошибке

Откройте [issue](https://github.com/VolkovIlia/gigamcp/issues/new/choose) и укажите:

- версию Chrome и расширения;
- что делали, что ожидали и что произошло;
- какой MCP-сервер подключали (адрес можно не указывать) и тип авторизации;
- ошибки из консоли фона: `chrome://extensions` → GigaMCP → «Service worker».

## Если сломалось после обновления giga.chat

Почти всегда виноваты селекторы вёрстки. Они собраны в объекте `SEL` в начале `extension/content/content.js`: поле ввода, кнопка отправки, сообщения пользователя и ответы. Найдите новые классы через «Просмотреть код» и поправьте их там.

Для отладки без установки расширения есть сборка с заглушкой фона:

```bash
cd test && npm install && node build-inject.cjs   # создаёт test/inject.min.js
```

Вставьте содержимое `inject.min.js` в консоль на странице giga.chat. Появится кнопка MCP с тестовым сервером `calc` (инструменты `add` и `now`).

## Перед pull request

```bash
cd test
npm install
node node-tests.mjs
npm i --no-save playwright && npx playwright install chromium
node e2e.mjs
```

Оба набора тестов должны проходить: CI запускает их на каждый PR.

## Стиль

- Без внешних зависимостей в самом расширении и мосте: только стандартные API браузера и Node.
- Тексты интерфейса — на русском, короткие и понятные.
- Логотип и иконки собираются скриптом `brand/build.py`, руками PNG не правьте.
