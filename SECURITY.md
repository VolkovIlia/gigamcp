# Безопасность

## Что расширение может и чего не делает

- **Доступ к сайтам.** Расширение просит `<all_urls>` только для того, чтобы фоновый скрипт мог обращаться к MCP-серверам по любому адресу без ограничений CORS. Интерфейс встраивается только в `giga.chat`.
- **Данные.** Адреса серверов, токены и OAuth-ключи хранятся в `chrome.storage.local` вашего браузера и отправляются только на соответствующие серверы. Никакой аналитики и сторонних запросов нет.
- **Вызовы инструментов.** По умолчанию каждый вызов нужно подтвердить. В авто-режиме модель может вызывать инструменты сама (не больше 12 шагов подряд), поэтому включайте его только для серверов, которым доверяете. Учтите, что содержимое веб-страниц и документов, которое читают инструменты, может пытаться управлять моделью (prompt injection).
- **Мост для stdio-серверов** запускает команды из вашего конфига. Он слушает только `127.0.0.1`, требует токен, отклоняет запросы со сторонних сайтов (по заголовку `Origin`) и с чужим `Host` (защита от DNS rebinding). Токен хранится в `~/.gigamcp-bridge/token`.

## Как сообщить об уязвимости

Не публикуйте уязвимость в открытом issue. Воспользуйтесь [приватным сообщением об уязвимости](https://github.com/VolkovIlia/gigamcp/security/advisories/new) на GitHub. Мы постараемся ответить в течение недели.
