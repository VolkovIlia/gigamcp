# Безопасность

## Что расширение может и чего не делает

- **Доступ к сайтам.** Расширение просит `<all_urls>` только для того, чтобы фоновый скрипт мог обращаться к MCP-серверам по любому адресу без ограничений CORS. Интерфейс встраивается только в `giga.chat`.
- **Данные.** Адреса серверов, токены и OAuth-ключи хранятся в `chrome.storage.local` вашего браузера и отправляются только на соответствующие серверы. Никакой аналитики и сторонних запросов нет.
- **Вызовы инструментов.** По умолчанию каждый вызов нужно подтвердить. В авто-режиме модель может вызывать инструменты сама (не больше 12 шагов подряд), поэтому включайте его только для серверов, которым доверяете. Учтите, что содержимое веб-страниц и документов, которое читают инструменты, может пытаться управлять моделью (prompt injection).
- **Помощник для локальных программ** (`extension/host/`) запускает только те команды, которые вы сами добавили в панели. Браузер стартует его через Native Messaging и пускает к нему только расширение GigaMCP (по ID в `allowed_origins`). Помощник не открывает сетевых портов; страницы сайтов и модель обратиться к нему не могут. Переменные окружения программ хранятся вместе с токенами в `chrome.storage.local`.
- **Папки компьютера в контексте.** Когда подключена хотя бы одна локальная программа, служебный контекст, который уходит в ГигаЧат, содержит путь к домашней папке, к «Документам» и рабочую папку программы — например `/home/имя_пользователя/Документы`, то есть и имя пользователя в системе. Без локальных программ эти пути не отправляются.
- **Flatpak-браузеры.** Чтобы помощник видел программы компьютера, установщик выдаёт браузеру разрешение `--talk-name=org.freedesktop.Flatpak`. С ним сам браузер может запускать команды вне песочницы, то есть песочница Flatpak для него перестаёт быть защитой. Удаление помощника это разрешение не отзывает (им могут пользоваться другие программы); команду для отзыва печатает `--uninstall`.
- **Установщик помощника.** Кнопка «Скачать установщик» собирает файл из кода самого расширения, без обращений в сеть, и сохраняет его в папку загрузок (для этого нужно разрешение `downloads`). Внутри — тот же `install-host.py` со встроенным помощником и ID вашей копии расширения; перед запуском его можно прочитать.
- **Заголовок Origin.** Разрешение `declarativeNetRequestWithHostAccess` убирает заголовок `Origin` только у запросов фона расширения (без вкладки) — как у Claude Desktop или Cursor, — чтобы MCP-серверы с защитой от DNS rebinding не отвечали 403. Запросы страниц сайтов не меняются.
- **Перехват кода OAuth.** Разрешение `webRequest` нужно только для одного: прочитать заголовок `Location` с кодом авторизации, если страница входа сервера запрещает браузеру перейти на адрес возврата (`form-action` в CSP). Запросы не изменяются и не блокируются.

## Как сообщить об уязвимости

Не публикуйте уязвимость в открытом issue. Воспользуйтесь [приватным сообщением об уязвимости](https://github.com/VolkovIlia/gigamcp/security/advisories/new) на GitHub. Мы постараемся ответить в течение недели.
